# Custom learning and responsive navigation — October 22, 2026

The home screen now has three task-based entries; arbitrary subjects and supplied material are separate from the six finite offline starters. Production learning uses the existing owner-private authenticated service without changing its audience or key storage. Both new learning paths receive one draft call and one independent audit; insufficient material and rejected drafts never get hidden substitutes or automatic retries.

A bounded real series tested Oceans, Shakespeare, historical New York Knicks material (topic-only), and an authored coastal-science lecture (material mode). Oceans and Shakespeare passed parsing and independent audit with multiple supported mechanics; the lecture produced four source-grounded literal groups and passed. The Knicks draft was rejected by the audit. A separate real UI Oceans request also reached the audit and was rejected, while its input remained available. These are beta diagnostics, not a claim of universal generation reliability or fresh web verification. Raw traces remain in ignored local fixtures.

Automated coverage includes arbitrary topics outside the catalog, longer material limits, exact excerpts, rejection of invented source terms, first-letter and anagram mechanics, the production audit gate, personal-data separation, preservation/restoration of long drafts, and uncovered-connection history. Existing personal creation, stored stories, sharing, game and tutorial tests are retained. Browser geometry checks at 320, 390, 768 and 1440 pixels found no horizontal overflow on home, material, personal and board screens. Mobile tiles measure 76 pixels high. Reading links are now optional post-discovery context. Physical iPhone/Android hardware, microphones, and every browser are not certified by these viewport checks.
