# Knowledge pack beta validation — October 21, 2026

Six finite test catalogs contain reviewed factual groups and phrase/word transformations. The model selects four catalog connections; it does not author unsourced facts. An independent call checks the complete partition before release. Personal stories are excluded from these requests.

Two bounded live generation series were run with Claude Haiku, with no automatic paid retries. The initial six-board series accepted three boards and rejected three: the reviewer misread subset wording and considered unshown alternatives to be competing answers. The code retained the rejection gate; audit instructions were corrected to judge displayed tiles and explicit false total claims, not ordinary non-exhaustive examples. Postal-code and Cabinet wording were clarified.

The next six generations included prior groups as novelty context. Five passed. Science was rejected because “Four states of matter” was read as an exhaustive claim despite the explanation's explicit qualification. The category now says “Familiar states of matter.” All six starter boards subsequently passed independent live audits, and the exact rejected science selection passed with the revised category. That recheck is a retained-selection review, not a new first-attempt generation success. The other final AI boards covered fill-blank, missing-first-word, missing-last-word, and first-letter removal; the initial General Knowledge response also selected anagrams. This small sample cannot guarantee future model judgments.

Automated tests cover all catalog mechanics and tile/explanation bounds, incomplete/unknown/duplicate selections, personal-data separation, bounded pack history, no all-literal AI boards, the production review gate, explicit failures with no fallback, instant solo play, spoiler-free entry, and recording only uncovered connections. Full existing frontend and service suites passed before the final wording correction, followed by focused pack checks, typechecking and a fresh production build. Raw model responses and token-usage details remain in ignored local fixtures; no API credentials or private stories are part of the catalog or report.
